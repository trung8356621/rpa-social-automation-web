# rpa-social-automation-web

React CSR admin UI for SEO-OPS Social Automation.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn-style primitives + Lucide
- Compact Desktop Control Center (see `docs/`)

## Scope (approved menus)

1. Action Tags  
2. Script Registry  
3. Accounts  
4. Clients (Browser-first)  
5. Client API Keys  

Realtime WebSocket Gateway lives in a **separate** repo (`rpa-social-automation-realtime`). Laravel SEO-OPS owns business data.

## Develop

```bash
pnpm install
pnpm dev
```
